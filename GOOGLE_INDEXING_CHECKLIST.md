## Red Flags to Watch

🚩 If GSC shows "Indexed, but not shown" error
   → Add more content to your service descriptions

🚩 If CSE shows coverage errors
   → Check index.html for broken tags

🚩 If site:sensoryark.com returns 0 results after 7 days
   → Double-check robots.txt is correct
   → Request indexing again in GSC

🚩 If you see crawl errors in GSC
   → Click the error, Google will explain what's wrong
