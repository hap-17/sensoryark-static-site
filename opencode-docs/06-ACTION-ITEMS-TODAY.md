## The 5-Step Process

### Step 1: Create Google Account (If Needed)

**Time: 2 minutes**

Go to: https://accounts.google.com

- If you have Gmail → You're done, skip to Step 2
- If you don't → Create a Google account first

---

### Step 2: Access Google Search Console

**Time: 1 minute**

Go to: https://search.google.com/search-console/

Click: **"Add property"** button (top left)

---

### Step 3: Add Your Website

**Time: 2 minutes**

**Dialog appears asking:**
```
"Select a property type"
```

**Choose:** "URL prefix" (left option)

**Enter:** `https://sensoryark.com`

Click: **"Continue"** button

---

### Step 4: Verify Ownership

**Time: 3 minutes**

**Google shows:**
```
"Verify ownership of sensoryark.com"
```

**Choose verification method:**
- Select: **"HTML tag"** (easiest method)
- Google gives you a `<meta>` tag
- I've already added it to your site ✓

**In Google Search Console:**
- Click: **"Verify"** button
- Wait: 5-30 seconds

**Result:**
```
✓ Property verified successfully
```

If it doesn't verify:
- Try refreshing the page
- Wait 1-2 minutes
- Try again

---

### Step 5: Submit Your Sitemap

**Time: 2 minutes**

**Inside Google Search Console:**

1. Click: **"Sitemaps"** (left menu)
2. See text field that says: "Add a new sitemap"
3. Enter: `https://sensoryark.com/sitemap.xml`
4. Click: **"Submit"** button

**Result:**
```
✓ Sitemap submitted successfully
```

---

### Bonus Step 5b: Request Indexing (Optional But Recommended)

**Time: 1 minute**

**In Google Search Console:**

1. Click: Top search bar (labeled "URL Inspection")
2. Type: `https://sensoryark.com`
3. Wait for result
4. Click: **"Request indexing"** button
5. See: "Indexing request received"

**Repeat for:**
- `https://sensoryark.com/#welcome`
- `https://sensoryark.com/#what-is-ot`
- `https://sensoryark.com/#services`
- `https://sensoryark.com/#contact`

**Why:** Speeds up crawling (24 hours instead of 3-7 days)

## Quick Troubleshooting

### "Verification Failed"
- Wait 5 minutes
- Refresh the page
- Try again
- If still failing: Read `07-STEP-BY-STEP-GSC-SETUP.md`

### "Can't Find My Site"
- Make sure you're using: `https://sensoryark.com` (with https)
- Not: `http://sensoryark.com` (without s)
- Not: `www.sensoryark.com` (has www)

### "Sitemap Not Submitting"
- Use exact URL: `https://sensoryark.com/sitemap.xml`
- Not: `sensoryark.com/sitemap.xml`
- Not: `/sitemap.xml`
